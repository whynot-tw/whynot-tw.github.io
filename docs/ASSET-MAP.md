# Website v4｜素材對照表

狀態：Approved asset map

## Brand Source

正式品牌素材由使用者提供，網站僅能依正式素材裁切、去背、格式轉換與部署。

禁止：

- 重新設計 Logo
- 修改品牌字型
- 修改比例
- 自行創造新的品牌版本
- 使用 HTML 文字字元代替正式 Logo

## Placeholder Assets

Placeholder 優先使用 HTML/CSS 元件，不建立大量重複圖片。

規格：

- 淺灰底
- 黑色細線
- 中文「建置中」
- 中文副標
- 不引用不存在的圖片路徑

## Footer Icons

使用內嵌 SVG 或專案內可維護 SVG。

實際項目：

- FAQ
- Email
- Instagram
- LINE

禁止以 `?`、`✉`、`◎`、`＋` 等文字字元假裝正式 icon。

## QR Code

LINE 官方帳號 QR Code 暫時維持目前來源與樣式，不在 Website v4 重建時重新生成或修改。

## Cache Versioning

CSS、JS、圖片更新後需同步更新 query string 或檔名，避免 GitHub Pages 與瀏覽器快取顯示舊版。
