# Visual QA Checklist

Status: Approved
Updated: 2026-07-30

## Work cards

- Media ratio is consistent.
- Media height is consistent within the same grid.
- Image-to-title spacing uses the approved generous rhythm.
- Title-to-category spacing is consistent.
- Card-to-card spacing is consistent.
- Placeholder and published cards share the same component geometry.
- Published cards have consistent hover, focus and pointer feedback.
- The complete published card is clickable.
- Placeholders remain non-clickable.
- Homepage and Works use the same internal card spacing.
- Mobile and desktop are checked separately.
- Browser default margins on figure, headings and paragraphs do not alter the component rhythm.

## Navigation

- Logo returns to the homepage.
- Current section is identified.
- Case pages link to independent About, Services, Works and Contact pages.
- Breadcrumb and return-to-Works links are valid.
- Mobile menu opens, closes and updates aria-expanded.

## Release evidence

Do not describe a visual change as verified until it has been rendered and checked at mobile and desktop widths. Code review alone is not visual QA.
