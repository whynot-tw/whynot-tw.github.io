# Website v4｜集中版面修正清單

狀態：Open｜待集中修正

## 修正原則

- 不逐頁零碎修改。
- 先完成全站問題盤點，再依共用樣式、核心頁、案例頁順序一次處理。
- 優先修正影響多頁的共用 CSS 與元件，避免同一問題重複修改。
- 視覺修正不得改動已確認內容、品牌素材與案例資料。

## 已確認的結構性問題

### 全站共用

- [ ] 頁面標題與首頁 Hero 的字級規則需分離，避免所有 `h1` 套用同一個超大尺寸。
- [ ] Header Logo 實際比例與 Header 高度需重新校正。
- [ ] Section 上下留白過大，需建立桌機／平板／手機一致的間距階層。
- [ ] Footer 仍以文字膠囊模擬 icon，與規格要求的正式圓形 SVG icon 不符。
- [ ] 英文 eyebrow（Portfolio、About、Services、CONTACT）依「非必要英文移除」規則統一處理。
- [ ] 各頁 Footer 標籤與文字格式不完全一致。
- [ ] CSS／JS cache version 需統一。

### 首頁

- [ ] Hero 主標目前為長句，與已定案的品牌名稱＋正式副標規則不一致。
- [ ] Hero 高度與文字寬度需重新配置。
- [ ] 精選作品桌機欄數、卡片比例與留白需統一。
- [ ] Placeholder 與正式圖片卡片的視覺重量需平衡。
